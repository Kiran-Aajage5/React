# 🍔 Food Delivery App (React + Swiggy API)

This is a simple and responsive food delivery application built using **React**. It fetches data from the **Swiggy API** to display food items dynamically, focusing on UI rendering, API integration, and component-based architecture.

## 🚀 Features

- Dynamic food item rendering from API
- Component-based structure using React
- Asynchronous data fetching with `fetch()`
- Responsive and user-friendly UI
- Organized with reusable components
- Basic routing and state management

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Swiggy API (publicly available data)
- HTML5 & CSS3
- Git & GitHub
